# Security Policy

## Supported Versions

The `main` branch is the supported version of this template.

## Reporting A Vulnerability

Please open a private security advisory or contact the repository maintainer if you find a vulnerability.

Do not open public issues containing credentials, real guest data, private URLs, or exploit details.

## Template Safety Checklist

- Keep `.env` and `.env.local` out of git.
- Use a separate Supabase project for every wedding.
- Review Row Level Security policies before launch.
- Rotate any key that has ever been committed.
- Remove sample data before inviting real guests.
