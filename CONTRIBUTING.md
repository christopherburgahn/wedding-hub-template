# Contributing

Thanks for helping improve Wedding Hub Template.

## Local Development

```sh
npm install
npm run dev
```

Run these checks before opening a pull request:

```sh
npm run lint
npm run build
```

## Pull Requests

- Keep changes reusable for many weddings, not specific to one couple or venue.
- Do not commit private event data, guest lists, photos, passcodes, or credentials.
- Prefer small focused pull requests with a short description and screenshots for UI changes.
- Update the README when setup or behavior changes.

## Privacy

This repository is intended as a safe template. Contributions that add real personal data, private integrations, or hardcoded project IDs will be removed.
